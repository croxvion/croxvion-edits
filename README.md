# CROXVION EDITS — Hindu Indian Wedding Portfolio

A standalone, responsive portfolio website for Rishi. It is focused exclusively on Hindu Indian wedding photo editing and color finishing. It does not carry the original reference company's branding.

## Regional galleries
- South Indian Hindu weddings: Tamil, Telugu, Kannada and Kerala visual references
- North Indian Hindu weddings, including Delhi-style references
- Bengali and East Indian Hindu weddings
- Gujarati and West Indian Hindu weddings
- Rajasthani Hindu weddings
- Central Indian Hindu weddings

Each regional gallery contains 30 stock demonstration frames. Image sets are mixed by region and ceremony/editing focus; some broadly applicable Hindu wedding references may appear across more than one region. They are not presented as Rishi's client work or as before/after results.

## Publishing
Upload the ZIP contents to a static host (Netlify, GitHub Pages, or any web host). Keep the files in the same directory. The photos are loaded from Pexels, so live internet access is required for the image gallery.
